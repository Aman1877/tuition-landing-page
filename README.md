# 📘 Tuition Landing Page

A modern, responsive landing page for a tuition teacher, designed using **React**, **Vite**, **Tailwind CSS**, **ShadCN UI**, and **Framer Motion**.

---

## 📌 Features

- 🎯 Clean, scroll-smooth navigation
- 🎓 About the teacher section
- 📚 Class subjects and features
- 🌟 Student & parent testimonials
- 📞 Contact form with validation
- 🎈 Scroll-to-top button
- ✨ Smooth animations with Framer Motion
- 💡 Responsive design

---

## 🧱 Built With

- ⚛️ React
- ⚡ Vite
- 🎨 Tailwind CSS
- 🧩 ShadCN UI
- 🎞 Framer Motion
- ✅ Zod + React Hook Form
